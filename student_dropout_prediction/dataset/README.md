# Dataset: Predict Students' Dropout and Academic Success

This directory houses the benchmark student dataset obtained from the official **UCI Machine Learning Repository**.

---

## 📌 Dataset Source & Information
- **Repository**: [UCI Machine Learning Repository (Dataset ID: 697)](https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success)
- **Creators**: Valentim Realinho, Mónica V. Martins, Jorge Machado, Luís Baptista (Instituto Politécnico de Portalegre, Portugal).
- **Domain**: Higher Education Student Retention & Academic Performance.
- **Total Records (Instances)**: 4,424 students.
- **Total Features**: 36 predictive attributes + 1 Target column.
- **Missing Values**: 0 (Clean complete records).
- **Duplicate Rows**: 0 (Every row represents a unique student).

---

## 📁 Files in This Directory

1. **`predict_students_dropout_and_academic_success.zip`**:
   The exact, untouched ZIP archive downloaded directly from the official UCI repository.
2. **`data.csv`**:
   The original extracted raw dataset (semicolon-delimited `;`, encoded in UTF-8 with BOM `utf-8-sig`).
3. **`student_data_clean.csv`**:
   Standard comma-separated (`.csv`) version generated by `load_dataset.py`. Column headers have been trimmed of trailing tabs/spaces (e.g. `Daytime/evening attendance\t` -> `Daytime/evening attendance`). All 4,424 rows and 37 columns of original student data are 100% preserved.

## 🎯 Target Variable (`Target`)

The primary target column is **`Target`**, which classifies the student's academic status into 3 categories:

| Target Class | Description | Student Count | Percentage (%) |
| :--- | :--- | :---: | :---: |
| **Graduate** | Student successfully completed their degree program | 2,209 | 49.93% |
| **Dropout** | Student dropped out / discontinued their degree program | 1,421 | 32.12% |
| **Enrolled** | Student was actively enrolled at the time of data collection | 794 | 17.95% |
| **Total** | | **4,424** | **100.00%** |

## 📊 Feature Breakdown (36 Features)

The 36 features capture a 360-degree view of student progress and circumstances:

### 1. Demographic Indicators
- `Marital status`: Categorical code (Single, Married, Divorced, etc.).
- `Nacionality`: Country of origin code.
- `Gender`: Student gender (1: Male, 0: Female).
- `Age at enrollment`: Age of the student when entering the program (integers from 17 to 70).
- `International`: Whether the student is an international scholar (1: Yes, 0: No).
- `Displaced`: Whether the student had to relocate from their hometown (1: Yes, 0: No).
- `Educational special needs`: Whether the student has recognized special learning needs (1: Yes, 0: No).

### 2. Socio-Economic Factors
- `Mother's qualification` & `Father's qualification`: Parental highest educational level codes.
- `Mother's occupation` & `Father's occupation`: Parental employment category codes.
- `Debtor`: Whether the student has outstanding debts with the university (1: Yes, 0: No).
- `Tuition fees up to date`: Whether university tuition fees are fully paid (1: Yes, 0: No).
- `Scholarship holder`: Whether the student is a financial scholarship recipient (1: Yes, 0: No).

### 3. Academic Entry Background
- `Application mode`: Admission pathway code (e.g., general exam, international agreement).
- `Application order`: Priority preference of this degree (1st choice, 2nd choice, etc.).
- `Course`: Specific degree program code (Nursing, Informatics, Management, etc.).
- `Daytime/evening attendance`: Class schedule (1: Daytime, 0: Evening).
- `Previous qualification`: Highest prior schooling code.
- `Previous qualification (grade)`: GPA / grade from prior schooling (0–200 scale).
- `Admission grade`: Entrance exam score (0–200 scale).

### 4. 1st Semester Performance
- `Curricular units 1st sem (credited)`: Number of credits recognized from prior studies.
- `Curricular units 1st sem (enrolled)`: Number of subjects registered in semester 1.
- `Curricular units 1st sem (evaluations)`: Number of exam/assignment evaluations taken.
- `Curricular units 1st sem (approved)`: Number of subjects passed in semester 1.
- `Curricular units 1st sem (grade)`: Average grade in semester 1 (0–20 scale).
- `Curricular units 1st sem (without evaluations)`: Subjects unattended without examination.

### 5. 2nd Semester Performance
- `Curricular units 2nd sem (credited)`: Number of credits recognized in semester 2.
- `Curricular units 2nd sem (enrolled)`: Number of subjects registered in semester 2.
- `Curricular units 2nd sem (evaluations)`: Number of exam/assignment evaluations taken.
- `Curricular units 2nd sem (approved)`: Number of subjects passed in semester 2.
- `Curricular units 2nd sem (grade)`: Average grade in semester 2 (0–20 scale).
- `Curricular units 2nd sem (without evaluations)`: Subjects unattended without examination.

### 6. Macroeconomic Context
- `Unemployment rate`: National unemployment rate (%) during the academic year.
- `Inflation rate`: National inflation rate (%) during the academic year.
- `GDP`: Gross Domestic Product growth rate (%).
